# File Operation Commands

```sh
ls
```
> List files and directories in the current directory


```sh
cd [directory]
```
> Change the current directory to the speicified directory


```sh
pwd
```
> Print the current working directory


```sh
mkdir [directory]
```
> Create a new directory


```sh
rmdir [directory]
```
> Remove an empty directory


```sh
rm <file>
```
> Remove a file


```sh
rm -r [directory]
```
> Remove a directory and its contents recursively


```sh
cp [source] [destination]
```
> Copy a file or directory (source) under "destination" directory


```sh
mv [source] [destination]
```
> Move or rename a file or directory (source) under "destination" directory


```sh
touch [file]
```
> Create a new empty file or update the timestamp of an existing file


```sh
cat [file]
```
> Display the content of a file


```sh
less [file]
```
> Viev the contents of a file page by page


```sh
echo [text] > [file]
```
> Write text to a file (overwriting)


```sh
echo [text] >> [file]
```
> Append text to a file


```sh
chmod [mode] [file]
```
> Change the permissions of a file


```sh
chmod [owner] [file]
```
> Change the owner of a file


```sh
chmod [group] [file]
```
> Change the group of a file
